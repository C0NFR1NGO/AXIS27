# AXIS'27 Redesign: Dune + Detroit: Become Human

## Goal

Deepen and refine the existing Dune/Detroit visual identity. The site already has partial Dune (spice-gold) and Detroit (cyber-blue LEDs, scanlines, instability indicators) theming — this redesign pushes both aesthetics further while preserving ALL content, text, data, and information verbatim.

## Design Direction

**Dune (Arrakis):** Deep obsidian backgrounds, spice-gold/amber accents, sand textures, desert haze gradients, ornithopter HUD overlays, cinematic particle dust, the "spice melange" golden glow.

**Detroit: Become Human (CyberLife):** Holographic LED panels (cyan), glass-morphism cards with razor-thin borders, monospace system readouts, status indicators, the angular HUD overlay frame, software instability glitch effects, the CyberLife blue LED dot motif.

## Changes

### 1. `src/styles/global.css` — Design System Overhaul

**Variables (`:root`):**
- Expand palette: add `--spice-sand`, `--spice-haze`, `--dune-ember` for Dune depth; add `--cyber-led`, `--cyber-hologram`, `--cyber-panel` for Detroit clarity
- Add `--font-accent: 'Ethnocentric', sans-serif` (currently no CSS var for this)
- Add easing tokens: `--ease-spice: cubic-bezier(0.16, 1, 0.3, 1)` for Dune cinematic reveals
- Add `--border-glow: rgba(0, 229, 255, 0.08)` for HUD frame
- Keep all existing variable names for backward compat, but refine values

**Body background:** Deeper obsidian gradient with subtle sand-haze radial tint

**Body `::after` overlay:** Refine the scanline + LED column effect — cleaner, less noisy, more deliberate Detroit HUD feel. Reduce opacity to ~0.25 (from 0.4)

**Desktop `::before` HUD frame:** More prominent — thin cyan lines at edges with corner bracket accents (Detroit: Become Human menu frame)

**`.section` top hairline:** Refine gradient to include amber→cyan→amber (spice→LED→spice)

**`.glass-card`:** Sharper — increase backdrop-blur, add subtle top-edge cyan glow line, refine hover to include holographic shimmer

**Buttons:** Add micro-animation on hover — subtle glow pulse. `.btn-primary` gold glow stronger on hover. `.btn-secondary` cyan glow

**New keyframes:**
- `hud-scan` — horizontal scan-line sweep across element (Detroit holographic scan)
- `spice-glow` — gentle amber pulse (Dune spice breathing)
- `led-breathe` — refined LED pulse with smoother easing

**Fix duplicated scanline rule** (lines 86-106 and 200-221 are duplicate — remove the weaker first copy)
