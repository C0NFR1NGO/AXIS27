# AXIS'27 Website Redesign — Desert + Android Theme

## Vision

**Dune's vast desert landscapes** (warm amber, sand textures, spice gold) merged with **Detroit: Become Human's clean android UI** (smooth glass panels, blue LED accents, precise geometric layouts). Cinematic, immersive, and distinctly different from the current implementation.

## Key Design Differences from Current

The current theme already references Dune/DBH but uses a scattered approach — too many competing elements (3D particle background, glitch effects, diagnostic terminals, instability percentages everywhere). The new design will be **cohesive and intentional**:

| Aspect | Current | New |
|--------|---------|-----|
| Background | 3D Three.js constellation field | Layered CSS sand-dune atmosphere with subtle parallax |
| Color balance | Gold + Cyan equal | Warm sand-dominant with precise cyan LED accents |
| Cards | Dark glass with gold borders | Frosted desert glass with subtle blue LED edge-lit borders |
| Splash screen | Diagnostic terminal with 10 log lines | Cinematic desert sunrise boot with minimal android diagnostics |
| Typography | Ethnocentric + Orbitron + Cinzel (3 display fonts) | Consolidated to 2: a cinematic serif + clean mono |
| Animations | Heavy — particles, glitch, instability jitter | Refined — sand drift, LED pulse, smooth reveals |
| HUD elements | Everywhere (corners, nav, footer, hero) | Strategic — hero corners + nav only |
| Cursor | Glowing cyan orb | Clean LED dot with sand-gold hover ring |

## Design System

### Color Palette (CSS Variables)
```
--desert-deep: #0a0704         /* Deep desert night */
--desert-dark: #12100c         /* Primary background */
--desert-surface: #1c1814      /* Card backgrounds */
--desert-sand: #c4a265         /* Primary warm accent (Dune spice) */
--desert-sand-light: #dbb876   /* Lighter sand */
--desert-amber: #a67c3d        /* Deeper amber */
--desert-glow: rgba(196,162,101,0.4) /* Sand glow */

--android-blue: #00c8ff        /* CyberLife LED blue */
--android-blue-dim: rgba(0,200,255,0.15)
--android-blue-glow: rgba(0,200,255,0.35)

--android-red: #ff2d4a         /* Instability / alert */
--android-red-dim: rgba(255,45,74,0.2)

--text-bright: #f0ece4         /* Primary text */
--text-soft: #c8bfae           /* Secondary text */
--text-ghost: #7a7165          /* Muted / labels */
```

### Typography
- **Display/Headlines**: `'Cinzel', serif` — Cinematic, ancient, Dune-fitting (already imported)
- **UI/Navigation/Labels**: `'Share Tech Mono', monospace` — Android diagnostic feel (already imported)
- **Body**: `'Rajdhani', sans-serif` — Clean, readable (already imported)
- Remove `Orbitron` and `Ethnocentric` font imports (reduce to 3 fonts)

### Component Design Language
- **Cards**: `border-radius: 3px`, frosted glass `backdrop-filter: blur(12px)`, 1px border `rgba(0,200,255,0.12)` with hover → `rgba(0,200,255,0.35)` + subtle blue glow
- **Buttons**: Sharp rectangular, 1px border, gold primary / blue secondary, smooth fill transitions
- **Dividers**: Single-pixel gradient lines (sand → blue → sand)
- **Section titles**: Cinzel serif, sand-gold gradient text, no shimmer animation (static elegance)
